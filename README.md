# PA트라슈 — Keystroke Dynamics 기반 파킨슨 조기 선별 서비스

> 웨어러블·설문 없이, 스마트폰에 편지 한 통 쓰는 것만으로 타이핑 리듬을 분석해
> 파킨슨병 조기 선별을 보조하는 디지털 헬스케어 서비스

키보드를 누르고 떼는 미세한 시간 차이(keystroke dynamics)에는 운동 기능의 변화가 담긴다.
PA트라슈는 사용자가 매일 "힐링레터"에 답장을 쓰는 동안 **글 내용이 아닌 입력 리듬만** 수집·분석하여,
검사에 대한 거부감 없이 일상 속에서 건강 신호를 확인할 수 있게 한다.

---

## 핵심 특징

- **No-Wearable** — 추가 장비 없이 스마트폰 하나로 완결 (고가 워치·센서 불필요)
- **비침습적 수집** — "검사"가 아닌 편지 답장 형태로, 심리적 부담 없이 데이터 확보
- **프라이버시 보호** — 편지 텍스트는 저장하지 않고 입력 리듬(누름/뗌 시각)만 활용
- **객관적 지표** — 주관적 설문 대신 ms 단위 물리적 행동 데이터 기반
- **해석 가능한 모델** — 로지스틱 회귀 계수로 각 특징의 기여도를 그대로 설명

---

## 모델 개요

공개 데이터셋(MIT CS1PD / CS2PD, 고유 참여자 85명 · Control 43 vs PD 42)의
키스트로크 기록에서 타이핑 관련 59개 지표를 추출하고,
통계 검증(상관분석 · t-test/Mann-Whitney · FDR 보정)과 VIF·Nested CV를 거쳐
**최종 3개 핵심 특징**으로 압축했다.

| 특징 | 의미 | 계수(기여도) |
|---|---|---|
| `hold_std` | 키 누름 시간의 변동성 (경직·리듬 붕괴) | 0.81 |
| `left_cv` | 왼손 타이핑 변동계수 (비대칭 발병) | 0.99 |
| `hold_p90` | 느린 구간 상위 10% (동결·머뭇거림) | 0.70 |

- **모델**: Logistic Regression (C=1.0, L2) + `SimpleImputer(median)` → `StandardScaler` 파이프라인
- **선택 근거**: 6개 후보 모델 중 최고 성능. 적은 표본(85명)에서 RF(0.75)·SVM(0.85) 대비 우수하고,
  계수 해석이 가능해 임상적 근거(좌우 비대칭)와 연결됨

### 검증 성능

| 교차검증 방식 | AUC |
|---|---|
| LOOCV | 0.860 |
| 5-Fold | 0.852 |
| 10-Fold | 0.862 |
| Nested CV | 0.853 |

> LOOCV(0.860) ↔ Nested CV(0.853) 차이가 0.007로 작아, 성능 과대추정 없이 안정적.
> (Accuracy 0.800 · Sensitivity 0.762 · Specificity 0.837 @ threshold 0.5)

### 점수화 로직

모델의 위험 확률을 사용자용 **건강 점수**로 변환: `점수 = 100 × (1 − 파킨슨 확률)`
학습 데이터에서 도출한 컷오프(민감도 85% / 특이도 85% 기준)로 3단계 판정한다.

- **안정** (66.6점 이상) — 정상에 가까움
- **관찰 필요** (49.9 ~ 66.6점) — 리포트 추이 살펴보기
- **상담 권장** (49.9점 이하) — 보호자 알림 · 의료 상담 안내

## 서비스 구성

| 기능 | 설명 |
|---|---|
| **힐링레터** | 매일 랜덤 질문에 답장 작성(최소 80자) → 입력 리듬 실시간 수집 |
| **멍멍우체부** | 화면 터치 미니게임으로 반응 속도·정확도 측정 (인지 기능 보조 지표) |
| **변화 리포트** | ML 기반 3단계 점수 표시 · 장기 추세 시각화 |
| **기록 보관함** | 날짜별 편지·점수 이력 조회 |
| **보호자 연동** | 이상 신호 시 리포트 원격 공유 |
| **접근성** | 고령층을 위한 폰트 크기 조절 등 반응형 UI |

---

## 기술 스택

- **Frontend / App**: Streamlit, HTML/JS (커스텀 keystroke 컴포넌트)
- **ML**: scikit-learn (Logistic Regression), pandas, numpy
- **데이터 수집**: `performance.now()` 기반 ms 단위 keydown/keyup 이벤트 페어링
- **리포트**: reportlab (PDF 생성)

---

## 프로젝트 구조

```
.
├── app.py                        # 메인 앱 (Streamlit 서버 · 화면/점수 표시)
├── logic.py                      # 예측 엔진 (raw 스트로크 요약 → 확률 → 점수)
├── train_model.py                # 모델 학습 스크립트
├── report_pdf.py                 # PDF 리포트 생성
├── charts.py                     # 추세 시각화
├── styles.py                     # UI 스타일
├── components/keystroke/         # 타이핑 리듬 수집 커스텀 컴포넌트
├── parkinson_model_3features.pkl # 학습된 모델 (hold_std, left_cv, hold_p90)
├── ml_score_thresholds.json      # 점수 구간 컷오프
└── requirements.txt
```

> 학습·실사용 일관성: `logic.py`의 특징 요약 규칙이 `train_model.py`와 동일해,
> 학습 때와 실제 추론 때 동일한 코드로 특징을 계산한다.

## 주의 및 한계

- 모델 `.pkl`은 scikit-learn 1.7.2 기준으로 생성. 환경 버전이 다르면
  `train_model.py`로 재학습해 `.pkl`을 다시 생성하는 것을 권장.
- 학습 표본이 85명으로 크지 않아, 성능 지표는 참고용으로 해석해야 함.
- **본 서비스는 의료기기가 아니며, 의학적 진단을 내리지 않는 선별 보조 도구입니다.**
  결과가 우려되면 신경과 전문의 상담을 권장합니다.
