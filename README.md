# PA트라슈 — Keystroke Dynamics 기반 파킨슨 조기 선별 서비스

> 웨어러블·설문 없이, 편지 한 통 쓰는 것만으로 타이핑 리듬을 분석해
> 파킨슨병 조기 선별을 보조하는 디지털 헬스케어 서비스

---

## 1. 프로젝트 개요

키보드를 누르고 떼는 미세한 시간 차이(keystroke dynamics)에는 운동 기능의 변화가 담깁니다.
PA트라슈는 사용자가 매일 "힐링레터"에 답장을 쓰는 동안 **글 내용이 아닌 입력 리듬만** 수집·분석하여,
검사에 대한 거부감 없이 일상 속에서 건강 신호를 확인할 수 있게 합니다.

- **No-Wearable** — 추가 장비 없이 키보드 입력만으로 완결 (현재 구현은 PC 키보드 기준, 아래 한계 참고)
- **비침습적 수집** — "검사"가 아닌 편지 답장 형태로 심리적 부담 없이 데이터 확보
- **프라이버시 보호** — 분석에는 입력 리듬(누름/뗌 시각)만 사용. 편지 본문은 기록 보관함에 보여 주기 위해 실행 중인 세션에만 보관하며 서버나 파일에 저장하지 않음
- **해석 가능한 모델** — 로지스틱 회귀 계수로 각 특징의 기여도를 그대로 설명

### 서비스 구성

| 기능 | 설명 |
|---|---|
| **힐링레터** | 매일 랜덤 질문에 답장 작성(최소 80자) → 입력 리듬 실시간 수집 |
| **멍멍우체부** | 화면 터치 미니게임으로 반응 속도·정확도 측정 (인지 기능 보조 지표) |
| **변화 리포트** | ML 기반 3단계 점수 표시 · 장기 추세 시각화 · PDF 리포트 |
| **기록 보관함** | 날짜별 편지·점수 이력 조회 |
| **보호자 연동** | 이상 신호 시 리포트 공유 (데모: 화면 안내만 하며 실제 전송은 구현되지 않음) |
| **접근성** | 고령층을 위한 폰트 크기 조절 등 반응형 UI |

## 2. 내 파트 — 모델링 · SHAP 해석/검증

팀 프로젝트이며, 서비스 전체(기획 · 앱 UI · 미니게임 · 리포트)와 **피처 선별 · EDA는 팀 작업**입니다.
본인은 **팀이 선별한 3개 피처를 받아 모델을 만들고, SHAP으로 모델의 판단 근거를 해석·검증**하는 파트를 맡았습니다.

📄 **발표자료 (내 파트: 모델링 및 소스 코드)** — [`docs/PA트라슈_모델링파트_발표자료.pdf`](./docs/PA트라슈_모델링파트_발표자료.pdf)

| 구분 | 내용 |
|---|---|
| **모델링** | 선별된 3-feature(`hold_std`, `left_cv`, `hold_p90`)로 6개 후보 모델 학습·비교 → 로지스틱 회귀 채택. 이 레포의 `train_model.py`는 채택한 모델의 LOOCV와 컷오프 산출만 담고 있음 |
| **SHAP 해석** | SHAP으로 각 피처의 기여 방향·크기를 시각화하고, 임상적 근거(변동성 증가 · 좌우 비대칭)와 방향이 맞는지 확인 |

**SHAP 피처 중요도** — 로지스틱 3특징의 평균 |SHAP| 기여도.
`left_cv`(0.69) > `hold_std`(0.63) > `hold_p90`(0.57)로, 표준화 계수 순서(0.99 > 0.81 > 0.70)와 일치.
세 특징 모두 위험을 높이는 방향이며, 왼손 변동이 가장 큰 신호(좌우 비대칭이라는 임상 근거와 부합).
표준화한 선형 모델에서는 평균 |SHAP|이 계수 크기에서 그대로 나오므로, 순서가 일치하는 것은 독립적인 검증이 아니라 같은 정보의 다른 표현입니다.

<img src="docs/img/shap_feature_importance.png" alt="로지스틱 3특징의 평균 |SHAP| 기여도" width="640">

**ROC · 혼동행렬 (LOOCV, threshold 0.5)** — AUC 0.860 · Accuracy 0.800 · Sensitivity 0.762 · Specificity 0.837.
교차검증: LOOCV 0.860 · 5-Fold 0.852 · 10-Fold 0.862 · Nested CV 0.853.

<img src="docs/img/roc_confusion_matrix.png" alt="ROC curve와 confusion matrix (LOOCV)" width="760">

**점수 분포 · 3구간 컷오프** — 점수 = 100 × (1 − 파킨슨 확률).
상한 66.6(민감도 85%) · 하한 49.9(특이도 85%)로 안정 / 관찰 필요 / 상담 권장을 나눕니다.

## 3. 모델 · 성능 · 실행법

### 데이터

- 공개 데이터셋 **MIT CS1PD / CS2PD** keystroke dataset
- 고유 참여자 **85명** (Control 43 · PD 42), 참여자 단위 요약 지표

### 입력 피처 (팀 선별)

팀의 EDA · 통계 검정을 거쳐 59개 타이핑 지표 중 **3개 핵심 피처**가 선별되었고, 이를 모델 입력으로 사용했습니다.

| 특징 | 의미 | 계수(기여도) |
|---|---|---|
| `hold_std` | 키 누름 시간의 변동성 (경직·리듬 붕괴) | 0.81 |
| `left_cv` | 왼손 키 누름 시간의 변동계수 (비대칭 발병) | 0.99 |
| `hold_p90` | 누름 시간 상위 10% (동결·머뭇거림) | 0.70 |

### 모델

- **Logistic Regression** (C=1.0, L2) — `SimpleImputer(median)` → `StandardScaler` → `LogisticRegression` 파이프라인
- **선택 근거**: 동일 조건(3변수 · LOOCV)에서 6개 후보 모델 중 최고 AUC.
  소표본(85명)에서 복잡한 모델은 과적합되며, 계수 해석이 가능해 임상적 근거(좌우 비대칭)와 연결됨
- **해석**: SHAP으로 피처별 기여를 시각화 (선형 모델이라 계수 해석과 같은 정보)

### 검증 성능

| 교차검증 방식 | AUC |
|---|---|
| LOOCV | 0.860 |
| 5-Fold | 0.852 |
| 10-Fold | 0.862 |
| Nested CV | 0.853 |

> 교차검증 방식에 따른 AUC 차이는 작습니다(0.852~0.862).
> (LOOCV 기준 Accuracy 0.800 · Sensitivity 0.762 · Specificity 0.837 @ threshold 0.5)
>
> 다만 이 수치들은 낙관적으로 치우쳤을 수 있습니다. 피처 3개가 같은 85명의 데이터에서 선별되었고
> 모델도 같은 데이터의 LOOCV AUC로 골랐기 때문에, 선별 과정까지 교차검증 안에 넣지 않은 Nested CV로는 이 편향이 걸러지지 않습니다.
> 표본이 85명이라 AUC의 불확실성도 큽니다(신뢰구간은 계산하지 않았습니다).
>
> K-Fold · Nested CV · 6개 모델 비교 · SHAP 분석 코드는 이 레포에 포함되어 있지 않고, 결과는 발표자료에 있습니다.
> `train_model.py`로 재현할 수 있는 것은 LOOCV 수치와 컷오프입니다(입력 CSV 필요).

### 점수화 로직

모델의 위험 확률을 사용자용 **건강 점수**로 변환: `점수 = 100 × (1 − 파킨슨 확률)`
LOOCV 확률로 도출한 컷오프(민감도 85% / 특이도 85% 기준)로 3단계 판정합니다.
컷오프도 같은 85명에서 정한 값이라, 민감도·특이도 85%는 외부 데이터에서 확인된 수치가 아닙니다.

- **안정** (66.6점 이상) — 정상에 가까움 (상한 = 민감도 85% 확보 지점)
- **관찰 필요** (49.9 ~ 66.6점) — 리포트 추이 살펴보기 (회색지대 16.7점)
- **상담 권장** (49.9점 이하) — 보호자 알림 · 의료 상담 안내 (하한 = 특이도 85% 확보 지점)

### 실행 방법

```bash
# 1. 의존성 설치
pip install -r requirements.txt

# 2. 앱 실행
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 접속. 학습된 모델(`parkinson_model_3features.pkl`)과
컷오프(`ml_score_thresholds.json`)가 포함되어 있어 별도 학습 없이 바로 실행됩니다.

**모델 재학습 (선택)**

```bash
python train_model.py
```

- 입력 파일 `4th_FINAL_2nd_summary_variables_subject_85rows.csv`(MIT 데이터에서 만든 참여자 단위 요약 지표)는
  레포에 포함되어 있지 않습니다. 같은 경로에 두면 LOOCV 성능 출력과 함께
  `.pkl` · 컷오프 JSON이 재생성됩니다.
- 모델 `.pkl`은 scikit-learn 1.7.2 기준이며, 환경 버전이 다르면 재학습을 권장합니다.

## 주의 및 한계

- 학습은 MIT 정제 파이프라인의 요약값 기준이며, 앱은 raw 키스트로크로 같은 3변수를 근사 계산합니다
  (요약값과 상관 약 0.92). 따라서 경계 근처에서는 판정 구간이 일부 달라질 수 있습니다.
- 학습 표본이 85명으로 작아, 성능 지표는 참고용이며 외부 데이터 재검증이 필요합니다.
- **학습 데이터와 사용 환경이 다릅니다.** 학습은 물리 키보드로 영문을 입력한 MIT 데이터이고, 앱은 한국어 자유 입력을 받습니다.
  입력 언어·기기에 따른 타이핑 리듬 차이가 점수에 미치는 영향은 검증하지 않았습니다.
- **현재 구현은 PC 키보드 기준입니다.** 키 누름·뗌 시각을 `keydown`/`keyup` 이벤트로 수집하는데,
  스마트폰 화면 키보드는 키별 이벤트를 제대로 전달하지 않는 경우가 많아 같은 방식으로 수집되지 않을 수 있습니다.
- **왼손 키 판별은 물리적 키 위치 기준입니다.** 이전 버전은 입력된 글자를 영문 글자와 비교했기 때문에,
  한글 입력에서는 왼손 키가 하나도 잡히지 않아 `left_cv`가 항상 0으로 계산됐고 점수가 "안정" 쪽으로 크게 치우쳤습니다.
  지금은 키 위치(`event.code`)로 판별하고, 왼손 타수가 부족하면 0이 아니라 결측으로 처리합니다.
  영향의 크기: 같은 모의 입력(누름시간 평균 0.11초, 표준편차 0.03초, 200타)에서 `left_cv`를 0으로 넣으면 97점(안정),
  실제 계산값(0.26)을 넣으면 62점(관찰 필요)이 나옵니다.
- **본 서비스는 의료기기가 아니며, 의학적 진단을 내리지 않는 선별 보조 도구입니다.**
  결과가 우려되면 신경과 전문의 상담을 권장합니다.
